# -111
Счетчик можно использовать в торговых центрах и магазинах (подсчитывать, сколько посетителей прошло за день, сколько ушло и в какие часы было больше всего людей), школах и лицеях (подсчитывать количество входящих и выходящих учеников, оценивать загруженность входа), офисах и бизнес-центрах (анализировать посещаемость и потоки сотрудников) и т. д.
